# Support

delegate-kit is maintained by [Thyra AI](https://github.com/Thyra-AI).

- **Bugs, questions, feature requests:** open an issue at
  <https://github.com/Thyra-AI/delegate-kit/issues>.
- **Pull requests** are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).
- **Docs:** [README.md](README.md), and the `/subagents` playbook shipped in
  `skills/subagents/SKILL.md`.

When reporting a problem, please include your Claude Code version (`claude --version`), your
OS, the delegate-kit version (`.claude-plugin/plugin.json`), and what you ran. Never paste
secrets or private code into a public issue.
